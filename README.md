# Ember

A private, consent-first intimacy game for adults (18+). Single-file web app: no build step, no server, no tracking. Everything is stored in the visitor's own browser.

## Publish on GitHub Pages (website only)
1. On github.com click **New repository**, name it (e.g. `ember`), keep it **Public** (free Pages), then **Create repository**.
2. Click **uploading an existing file**, drag in `index.html` and `README.md`, then **Commit changes**.
3. Go to **Settings > Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
4. After a minute your site is live at `https://YOUR-USERNAME.github.io/ember/`.
